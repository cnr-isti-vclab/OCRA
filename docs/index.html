Overview

A collaborative environment built for heritage documentation

OCRA supports conservation-restoration, technical art history, archaeology, and digital heritage workflows by combining advanced visualization, structured annotation, semantic interoperability, and cloud-connected publishing.

The platform integrates ThreePresenter for 3D inspection and OpenLIME for 2D and RTI exploration, creating a multi-view workspace where different specialists can work on the same project from different institutions.

OCRA adopts a decomposed annotation model: geometry, semantic data, and explicit links are treated as distinct but connected entities in a many-to-many model. This makes annotations reusable, auditable, and much better suited to complex interdisciplinary interpretation.

The result is not just a viewer with notes attached, but a structured research environment in which heritage evidence can be interpreted, revised, shared, and preserved over time.

Capabilities

Designed for concurrent work, semantic rigor, and cloud continuity

Multi-view annotation

Annotate 3D models, 2D images, and RTI assets directly in the browser with consistent project structure and shared semantic context.

Collaborative safety

Optimistic Concurrency Control, real-time mutation broadcasts, social locks, and structuring locks help teams collaborate without silent conflicts while preserving database consistency.

Semantic enrichment

Controlled vocabularies and ontology-driven structures make annotation content interoperable, reusable, and aligned with heritage knowledge standards.

User roles

User roles regulate who can edit projects, assets, and annotations, supporting clear responsibilities across collaborative workflows.

Controlled vocabularies

Controlled vocabularies support consistent, semantically grounded annotation authoring aligned with shared heritage knowledge standards.

ECCCH integration

Read, publish, update, and re-import Heritage Digital Twin data through ECCCH triple stores while preserving OCRA-specific project payloads.

Workflow

From authoritative sources to publishable heritage knowledge

01

Start or resume a project

Teams can import heritage metadata from ECCCH, ArCo, Wikidata, and Europeana, or import an existing OCRA project directly from ECCCH, including its OCRA payload, to continue previous work.

02

Build the project workspace

Teams associate 3D, 2D, and RTI assets with scenes, define vocabularies, and configure the annotation environment required for the study and documentation task.

03

Annotate collaboratively

Conservators, curators, and researchers work in parallel with live awareness, semantic consistency, and controlled conflict prevention mechanisms.

04

Publish and preserve

OCRA publishes structured knowledge to ECCCH, including graph content and OCRA-specific payloads so projects can be preserved, re-imported, and continued over time.

Why ECCCH

OCRA gains its full value inside the Cultural Heritage Cloud ecosystem

ECCCH provides the federated identity framework that allows distributed teams to collaborate securely across institutions and countries. It also provides the knowledge infrastructure required for shared semantic models, controlled vocabularies, and heritage metadata interoperability.

Through its integration with ECCCH triple stores, OCRA becomes more than a local annotation tool: it becomes a platform for producing interoperable, FAIR-oriented documentation that can circulate in the broader European Cultural Heritage Cloud.
